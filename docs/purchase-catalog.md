# 購入候補カタログ

`src/lib/purchase-catalog.ts` の `purchaseCatalog` に、商品詳細ページを確認した候補を登録します。埋め込みやベクトルDBは使わず、部品種別・抵抗値・LED色・基板モデルなどの構造化条件で候補を取得し、既存の商品選定処理に渡します。

## 動作

1. 既に取得したDigiKey候補を確認。
2. 適合候補がなければ登録済みページを最大3件まとめて確認。Google Searchによる商品発見を省略。
3. 登録候補も確認できなければ既存のWeb検索にフォールバック。確認済みのURLは再検索から除外。

登録情報だけで在庫あり・適合済みとは判定しません。ページ取得の成功、在庫、必要数量、入数、回路との適合性を確認できた商品のみ自動選択します。AIの利用上限やタイムアウトは既存の制限が適用されます。

購入モーダルの「登録済みの商品候補」は検索前や検索失敗時にも参照できます。未確認と明記した手動確認用リンクであり、カートには自動追加しません。DigiKey以外は販売店の商品ページを開きます。

## 追加方法

配列に一意な `id`、`name`、`store`、実在する商品詳細 `url`、`match`、`reviewedOn`、`enabled` を追加し、再デプロイします。管理画面・Firestore登録・自動学習は今回の実装には含みません。

- LED: `match: { kind: "led", color: "green" }`
- 抵抗: `match: { kind: "resistor", ohms: 10000 }`。330Ωと330kΩは別候補。
- 基板: `match: { kind: "board", board: "pico" }`
- ブレッドボード: `match: { kind: "breadboard" }`。400穴・30列を商品ページで確認。
- その他: `match: { kind: "dht22", value: "回路BOMの正確な値" }`。センサー型番、ピン数、電圧、プルアップ、ヘッダー等を事前確認。

価格・在庫は登録しません。`reviewedOn` は登録情報の確認日であり、現在の在庫確認日ではありません。販売終了や誤登録は `enabled: false` にします。同じURLは重複除外し、配列の先頭から最大3件を採用します。

初期登録は秋月電子の緑・赤LED、10kΩ抵抗、ブレッドボード2種の計5件です。各URLはコード内に記載。10kΩ抵抗は高精度品・10本パックのため、用途・価格次第で自動選択されない場合があります。他の部品は従来の検索を継続します。

検証: `npm test`、`npm run typecheck`。商品・在庫確認の外部AI/API呼び出しは単体テストでモック化しています。
