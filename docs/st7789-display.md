# ST7789 1.54インチ TFT液晶

対象は秋月電子通商の販売コード **131019**、型番 **M154-240240-RGB** です。OLEDではなく、ST7789V搭載の240×240ドットTFTカラー液晶です。既存の `ssd1306`（I2C OLED）とは別に `st7789` として登録しています。

## 使用方法

- 「対応するセンサー・部品」で `ST7789` / `M154-240240-RGB` を検索し、3Dプレビューから選択して回路生成を依頼します。
- Editorの「追加するパーツ」から配置・移動・反転できます。部品表、配線手順、CAD回路図、保存データにも8端子が反映されます。
- 購入候補にはURLの商品を登録しています。値は `M154-240240-RGB` を使用してください。在庫・価格は検索時に確認し、登録のみで購入可能とは判定しません。

## 接続

表示面を正面にし、ヘッダーを上に置いた図面の左から順に以下の8端子です。供給電圧は仕様表で2.4〜3.3V、本アプリでは3.3Vに統一します。電源・信号へ5Vを加えないでください。

| 端子 | 用途 | Breadberryでの接続 |
| --- | --- | --- |
| GND | 接地 | 基板のGND |
| VCC | 電源 | 基板の3V3 |
| SCL | SPIクロック | 出力可能なGPIO（SCK） |
| SDA | SPIデータ入力 | 出力可能なGPIO（MOSI） |
| RES | リセット、LOW有効 | 専用の出力GPIO |
| DC | データ/コマンド切替 | 専用の出力GPIO |
| CS | チップ選択、LOW有効 | 専用の出力GPIO |
| BLK | バックライト制御、HIGH点灯 | VCCから分岐した3.3V、または専用の出力GPIO |

I2Cアドレスはありません。MISO接続も不要です。SCL/SDAの印字を理由にI2Cバスへ接続しないでください。アプリは未接続、電源誤接続、信号の短絡、ESP32の入力専用GPIO34/35の使用、I2Cバスとの共有を検出します。CSやRESを固定レベルへ接続する構成は現在の検査対象外です。

ESP32/Pico/Raspberry Piで使用できますが、ファームウェアにはST7789対応ドライバが必要です。生成結果に記載されたライブラリの導入手順・240×240初期化・SPIピン設定を確認してください。現在のPiカタログにはSPI0のGPIO10/11がないため、公開済みGPIOとソフトウェアSPIに対応したドライバを組み合わせます。MicroPythonにST7789ドライバが標準搭載されているとは扱いません。今回、APIキー不要のST7789専用サンプルは追加していません。

## 3Dモデルと配置

`src/components/st7789-model.tsx` にThree.jsの形状として実装し、カタログと回路ビューで共有します。寸法は `src/lib/st7789.ts` に集約しています。

- 基板外形32×43.72mm、表示領域27.72×27.72mm。
- ピン間隔2.54mm、取付穴径2mm、穴中心間隔27×38.72mm。
- ブレッドボードの2.54mmピッチ＝0.24シーン単位で換算。
- 8本の端子は8列を占有します。AI生成時は全パーツに明示配置を指定し、従来の5列間隔配置を使わないよう指示しています。
- 反転時は端子順と基板本体の張り出し方向を同時に反転し、レイアウト検査にも本体寸法を反映します。
- ジャンパ線の挿入先は、液晶基板の外形と被覆の余裕を考慮した空き穴から選びます。液晶が覆う穴は、他部品や電源レールへの配線でも使用しません。
- 配置は端子列を `eN`（通常向き、N=1〜23）または `fN`（反転、N=8〜30）にすると分岐用の穴を確保できます。例: 液晶を `e9`、ボタンを `b23`。Raspberry Piの外部ヘッダーも本体で覆わないようにしてください。
- 液晶を含む回路では、線を空き穴から垂直に立ち上げ、画面より上で渡します。接続できる穴が足りない場合は配置エラーとして検出し、自動生成では再生成・修正の対象にします。Editorでは接続先を確保できない線を描画しません。

ヘッダー装着済みの平置きを想定した配線ガイド用モデルです。大きな基板のため、配置によってブレッドボードからの張り出し・他部品との重なりが表示されます。ヘッダーの実装状態・実物の印字を確認し、必要ならジャンパ線で引き出してください。厚さ、色、フレックスケーブル、小部品は模式表現を含み、製造用CADデータではありません。実機動作や液晶表示のシミュレーションは行いません。
